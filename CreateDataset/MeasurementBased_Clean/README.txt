In this folder, several scenarios for data collection are implemented. Below are details:
1) Same structure (GFLI_LCL), same parameters, different in noise level:
- Clean
- one_percent_noise
- five_percent_noise
2) Different structure GFLI_L(IBR1,2,3,5,6,9) vs GFLI_LCL(IBR4,7,8) with strong variant
- one_percent_noise_differentStructure
3) Same structure but different in parameters:
- one_percent_noise_sameIBRstructure
4) Different structure GFLI_L(IBR1,2,3,5,6,9) vs GFLI_LCL(IBR4,7,8) but less variant
- one_percent_noise_differentStructure_v2
